## Sanic app factory и запуск в dev-режиме

### Контекст

Приложение создается через функцию `create_app()`. Такой подход удобен для тестов и дальнейшего расширения проекта: все
подключение routes, настроек и будущих зависимостей будет происходить в одном месте.

### Проблема

После первого варианта реализации тесты проходили, но ручной запуск через PyCharm падал в dev-режиме Sanic.

Причина была в том, что Sanic dev-reloader ожидает, что приложение будет создано на уровне модуля, а не только внутри
блока:

```python
if __name__ == "__main__":
```

### Решение

Оставить фабрику приложения `create_app()`, но дополнительно создать глобальный объект приложения:

```python
app = create_app()
```

Для тестов использовать отдельное имя приложения:

```python
app = create_app("payment-ledger-api-test")
```
