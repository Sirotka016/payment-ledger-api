# Architecture

Проект разделен на несколько простых слоев, чтобы не смешивать HTTP-логику, бизнес-логику и работу с базой данных в одном месте.

## app

Главная папка приложения для хранения кода API.

## app/main.py

Точка сборки приложения. Здесь будет создаваться Sanic-приложение, подключаться routes и общие настройки.

## app/config.py

Файл настроек проекта. Через него приложение будет получать параметры окружения: подключение к базе данных, секретный ключ для JWT и секретный ключ для подписи webhook.

## app/routes

HTTP-слой приложения. Описывает endpoints: авторизация, получение данных пользователя, админские действия и webhook платежей.

## app/schemas

Схемы входных и выходных данных. Они нужны, чтобы явно описывать, какие поля принимает API и какие поля возвращает.

## app/services

Слой бизнес-логики. Здесь будут находиться правила приложения: авторизация, создание пользователя, обработка webhook, начисление баланса, защита от повторной транзакции.

## app/repositories

Слой работы с базой данных. Хранит функции, которые читают и записывают данные через SQLAlchemy.

## app/models

SQLAlchemy-модели. Они описывают таблицы базы данных: пользователей, администраторов, счета и платежи.

## app/core

Общие технические модули, которые используются в разных частях проекта: безопасность, JWT, проверка подписи webhook, общие ошибки.

## tests

Тесты проекта. В первую очередь будут проверять авторизацию, пользовательские endpoints, админские endpoints и webhook платежеи.

## docs

Документация проекта: описание задания, архитектура, API и принятые решения.
