# Task

Нужно реализовать асинхронное REST API для работы с пользователями, администраторами, счетами и платежами.

## Стек

- Python
- Sanic
- PostgreSQL
- SQLAlchemy
- Docker Compose

## Сущности

- Пользователь
- Администратор
- Счет
- Платеж

## Пользователь должен уметь

- авторизоваться по email/password;
- получить данные о себе;
- получить список своих счетов и балансов;
- получить список своих платежей.

## Администратор должен уметь

- авторизоваться по email/password;
- получить данные о себе;
- создавать, обновлять и удалять пользователей;
- получать список пользователей вместе с их счетами.

## Webhook платежей

Нужно реализовать endpoint, который принимает webhook от внешней платежной системы.

Webhook должен:

- проверять SHA256-подпись;
- проверять, есть ли счет у пользователя;
- создавать счет, если его нет;
- сохранять платеж в базе данных;
- начислять сумму на баланс счета;
- не начислять одну и ту же транзакцию повторно.

## Стартовые данные

В миграции должны быть созданы:

- тестовый пользователь;
- счет тестового пользователя;
- тестовый администратор.

## Запуск

Проект должен запускаться двумя способами:

- через Docker Compose;
- локально без Docker Compose.

В README должны быть указаны тестовые email/password.
