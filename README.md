# Payment Ledger API

Асинхронное REST API для тестового backend-задания на Python.

Проект будет реализовывать работу с пользователями, администраторами, счетами и платежами. Отдельная часть проекта - webhook для обработки пополнения баланса от внешней платежной системы.

## Стек

- Python 3.11
- Sanic
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker Compose
- pytest

## Статус

Проект находится в разработке.
